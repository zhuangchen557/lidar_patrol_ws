# Enzo 巡迹实验台

这是巡检车前期可行性实验软件。0.2.0 版本支持换电脑后自动发现设备。当前
Windows 电脑作为实验控制电脑，直接连接：

- 自动识别：LES11B-MC-S1 USB 温湿度传感器（Modbus RTU，9600 8N1）
- 自动识别：LDROBOT LD19 激光雷达（230400，只读数据流）
- `192.168.0.7:5578`：USR-CAN115 底盘网关（当前只做连通检测）

软件由 Vue 界面、FastAPI 实验网关和桌面外壳组成。本机已配置 WSL2、
Ubuntu 22.04、ROS2 Humble 与 rosbridge；双击实验台时会自动唤醒
rosbridge，不需要提前打开终端。ROS2 不可用时，USB/CAN/雷达实验仍可独立运行。

## 使用前检查

1. 小车必须固定，任何运动测试前必须架空四轮并准备硬件急停。
2. Windows 有线网卡设置为 `192.168.0.100/24`，网关和 DNS 留空。
3. 插入设备后软件会扫描 Windows 当前全部 COM 口，不要求沿用原电脑的编号。
4. 关闭会占用串口的调试工具。同一个串口一次只能由一个程序打开。

## 换电脑首次使用

1. 解压完整文件夹，不要只复制 exe。
2. 插入温湿度传感器和 LD19；软件会通过真实协议响应识别设备，而不是猜测 COM 编号。
3. 如页面显示“未发现串口”，先在设备管理器检查串口驱动。
4. 如页面显示“可能被占用”，关闭串口助手、厂商工具或另一个实验台进程。
5. 底盘仍使用 `192.168.0.7:5578`，新电脑的有线网卡需与其处于同一网段。
6. WSL 设为 `auto` 时使用 Windows 默认发行版；如 ROS2 位于非默认发行版，可在
   `experiment-config.json` 中把 `wsl.distro` 改成实际名称。

软件会持续重试，因此可以先打开软件再插入设备，也能在 USB 端口编号变化后自动恢复。

## 当前验证内容

- 温湿度每秒采集并绘制历史趋势
- CAN115 地址及 TCP 端口连通检测
- LD19 数据帧、CRC、转速和二维扫描点实时解析
- 设备掉线、数据超时和环境阈值提示
- 演示模式与真实设备模式切换
- ROS2 标准接口：`/sensor/temperature`、`/sensor/humidity`、
  `/sensor/noise`、`/odom`、`/battery_state`、`/patrol/state`

## 本机 ROS2 状态

- ROS2 发行版：Humble（Ubuntu 22.04 / WSL2）
- rosbridge 地址：`ws://127.0.0.1:9090`
- 服务名称：`rosbridge.service`
- 温度、湿度、噪声消息类型：`std_msgs/msg/Float32`
- 里程计消息类型：`nav_msgs/msg/Odometry`
- 巡检状态和高层命令：`std_msgs/msg/String`

rosbridge 仅监听本机回环地址，不向局域网公开 9090 端口。当前未配置控制密码，
因此软件保持只读监控状态，不会向小车发送运动命令。

## 安全边界

当前一体化软件不会直接向底盘发送运动帧。页面中的真实巡检控制只有在 ROS2、控制密码和安全状态都满足时才可能启用。底盘低速运动验证应使用组长仓库的 SDK，并单独执行现场安全流程。

## 分享给组员

正式便携包包含：

```text
EnzoPatrolLab-0.2.0-windows-x64/
├─ Enzo巡迹实验台.exe
├─ experiment-config.json
├─ 实验版使用说明.md
└─ resources/（程序运行文件，请勿删除）
```

组员解压整个文件夹后，连接硬件并双击 `Enzo巡迹实验台.exe` 即可。不要只单独复制 exe；它需要同目录中的运行文件。便携包不会替组员安装
WSL2/ROS2；未安装时只影响 ROS2 状态，USB 温湿度、雷达和底盘连通检测仍可使用。

## 源码开发

```powershell
npm.cmd install
npm.cmd run dev
```

网关依赖在 `gateway/requirements.txt`。桌面便携包由 `scripts/package-windows.ps1` 生成，输出在 `release` 文件夹中。
