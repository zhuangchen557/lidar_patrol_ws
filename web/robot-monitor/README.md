# 智能巡检车监控系统

项目由 Vue 3 监控网页和安全的 C++ 模拟后端组成。

## 当前功能

- 演示数据与 C++ 后端模式切换
- 温度、湿度、CO、噪声实时数据显示
- 最近30秒趋势和二维巡检轨迹
- 报警阈值提示
- 后端在线、离线和数据异常状态
- 开始、暂停、停止巡检命令测试

当前控制命令只改变模拟任务状态，不会驱动真实电机。

## 启动网页

```powershell
npm.cmd run dev
```

浏览器打开 `http://localhost:5173`。

## 数据模式

- `演示数据`：网页自己生成数据，不需要后端。
- `C++ 后端`：连接 `ws://localhost:8080/ws`。

C++ 模拟后端的构建和运行说明位于 `backend/README.md`。正式接入小车时保留网页协议，并把模拟数据源替换为 ROS2 订阅器。

## 公共展示版

`npm.cmd run build:public` 会生成只读公共版本。公共版本固定使用演示数据，隐藏后端入口和控制按钮，避免将真实小车控制能力暴露到互联网。
