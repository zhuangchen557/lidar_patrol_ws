# 巡检车开发环境 — 快速启动指南

## 推荐：一键启动

### Windows 侧（管理员 PowerShell）
```powershell
# 1. 先确认雷达 USB 的 busid（重启/拔插后 busid 会变，不要照抄！）
usbipd list    # 找 USB-SERIAL CH340，记下 BUSID（如 3-1）
# 2. 挂载到 WSL
usbipd attach --wsl Ubuntu --busid <你的busid>
```

### 直接双击运行
`docs/start_car.bat`
（自动：清理旧转发器 → 起 TCP 转发器 → WSL 里 modprobe + chmod + 编译 + 启动 bringup）

> **bat 已知问题**：
> - 若报 `'powershell' is not recognized`：改用完整路径 `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`
> - `start /b` 起的转发器会在 bat 退出后被杀，需按下方「转发器保活」方式手动重启

## 手动分步启动（排错用）

### 0. 检查 CAN115 网卡 IP（重启后必查！）
CAN115 通过 ASIX USB 网卡连接，**重启后静态 IP 会丢**（变成 169.254.x.x 自动地址），此时底盘连不上：
```powershell
# 查看 ASIX 网卡 IP（管理员 PowerShell）
Get-NetAdapter | Where-Object { $_.InterfaceDescription -like "ASIX*" } | Format-Table Name,Status,LinkSpeed
Get-NetIPAddress -InterfaceAlias "以太网 4" -AddressFamily IPv4
```
若 IP 是 `169.254.x.x` 或没有 `192.168.0.x`，管理员执行：
```powershell
$idx = (Get-NetAdapter | Where-Object { $_.InterfaceDescription -like "ASIX*" }).ifIndex
# 先把占用 192.168.0.100 的板载网卡改回 DHCP（避免冲突）
$idxR = (Get-NetAdapter | Where-Object { $_.InterfaceDescription -like "Realtek*" }).ifIndex
netsh interface ip set address name=$idxR source=dhcp
# 再给 ASIX 网卡设静态 IP
netsh interface ip set address name=$idx static 192.168.0.100 255.255.255.0
# 验证：ping 192.168.0.7 通
```

### 1. 起底盘转发器（Windows，注意保活）
底盘连不上时 chassis_node 会报 `Connection refused` 并进模拟模式：
```powershell
python "E:\WeChat Files\wxid_tztqgtbzdb2m12\FileStorage\File\2026-08\23生产实习\docs\forward_5578.py"
```
> **保活**：直接用终端跑，Ctrl+C 或关窗口会死。需要常驻用：
> ```powershell
> Start-Process -WindowStyle Hidden -FilePath "python" -ArgumentList "E:\...\docs\forward_5578.py"
> ```
> 确认：`netstat -ano | findstr 5578` 有 LISTENING 即成功。

> **注意**：转发器为单客户端模式，新连接会自动断开旧连接。如果之前已有一个转发器在跑，新起的会自动接管。

### 2. 挂载激光雷达（管理员 PowerShell）
```powershell
usbipd list    # 找 CH340 的当前 busid（不固定！）
usbipd attach --wsl Ubuntu --busid <busid>
usbipd list    # 确认 Attached
```

### 3. 加载雷达串口驱动（WSL 里）
```bash
sudo modprobe ch341
sudo chmod 666 /dev/ttyUSB0
ls /dev/ttyUSB0    # 确认存在
```

### 4. 启动整车（WSL 里，含底盘+雷达+TF）
```bash
cd ~/lidar_patrol_ws && source install/setup.bash
ros2 launch vehicle_bringup bringup.launch.py
# 预期：YK_CAN SDK 已加载，已连接 CAN115(127.0.0.1:5578) + 雷达 normal + TF 正常
```

## 日常使用命令

### 键盘遥控（新终端）
```bash
cd ~/lidar_patrol_ws && source install/setup.bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
# 按键: i=前进  ,=后退  j=左转  l=右转  k=停
```

### 查看话题 / 里程计 / 雷达
```bash
ros2 topic list
ros2 topic echo /odom --once
ros2 topic echo /scan --once     # 360° 点云
```

### Rviz2 可视化（WSL 里）
```bash
cd ~/lidar_patrol_ws && source install/setup.bash
rviz2
# 1. Fixed Frame 改为 base_laser（或 odom）
# 2. Add → By topic → /scan → LaserScan（看雷达点云）
# 3. Add → TF（看坐标变换）
# 4. Add → By topic → /odom → Odometry（看里程轨迹）
```
> **注意**：需要 WSLg 支持（Windows 11 自带），RViz 窗口会自动弹到桌面。

### 落地旋转标定（改 MAX_ANGULAR_SPEED 用）
```bash
cd ~/lidar_patrol_ws && source install/setup.bash
# 只起底盘（雷达可不开）：
ros2 run vehicle_bringup chassis_node
# 另开终端：
python3 scripts/recalibrate_rot.py
```
> 步骤：车放地面、周围 1m 清空、车头做标记 → 回车后满速转 4 秒 → 数实际圈数（可小数）→ 输入圈数，脚本给出新 MAX_ANGULAR_SPEED 推荐值 → 改 chassis_node.py 第 18 行 → `colcon build --packages-select vehicle_bringup` 重启底盘。

### 路线录制 / 回放（空转或落地）
```bash
cd ~/lidar_patrol_ws && source install/setup.bash
# 录制：用键盘遥控走一遍
ros2 run navigation waypoint_recorder routes/my_route.json map_frame:=odom
# 回放（不经 Nav2 直发 /cmd_vel）
ros2 run navigation waypoint_player routes/my_route.json --ros-args -p use_nav2:=false
```

### 避障测试
```bash
cd ~/lidar_patrol_ws && source install/setup.bash
ros2 launch lidar_avoidance avoidance_test.launch.py
# 注意：不要和 waypoint_player 同时跑，会抢 /cmd_vel
```
> **避障逻辑**（已修复）：兼容 0~2π scan 角度格式；前方 <stop_distance 紧急停车；侧向 <stop_distance 触发转向避让。

### EnzoPatrolLab 实验台（Windows）
```
双击 Enzo巡迹实验台.exe
```
> **温湿度传感器**：需要 USB 温湿度模块（LES11B-MC-S1）插在电脑上，且对应 COM 口未被其他程序占用。gateway 会自动扫描 COM 口识别传感器。

## 已知问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| chassis_node 报 Connection refused | 转发器没起，或 CAN115 网卡 IP 丢了 | 先查 ASIX 网卡 IP（见步骤 0），再起转发器（见步骤 1） |
| CAN115 ping 不通 | 重启后 ASIX 网卡静态 IP 丢失变 169.254.x.x | 管理员重设 192.168.0.100/24（见步骤 0） |
| 转发器随 bat 关闭就死 | `start /b` 进程随控制台退出被杀 | 用 PowerShell Start-Process -WindowStyle Hidden 常驻启动 |
| bat 报 'powershell' is not recognized | PATH 里没有 powershell | bat 里改用 `%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe` |
| 雷达 /dev/ttyUSB0 不存在 | USB 没重挂，或 busid 变了 | `usbipd list` 找当前 busid → attach → modprobe ch341 + chmod 666 |
| 地面转弯无力、轮子轻微动 | MAX_ANGULAR_SPEED=16 是悬空标定值 | 跑落地旋转标定（见上文），改 chassis_node.py 第18行 |
| 避障只往左转、右边永远 inf | 旧版 sector_min 有角度过滤 bug | 已修复（809f328），更新代码即可 |
| Ctrl+C 退出报 context 失效 | 已知修复（59cc646 同类） | 已修复，无需处理 |
