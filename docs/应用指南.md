## 1. 系统概览

```
[Windows 主控机]
 ├─ EnzoPatrolLab 实验台.exe   ← USB 温湿度(Modbus RTU) + 数据平台(演示/真实)
 ├─ forward_5578.py            ← TCP 转发器 127.0.0.1:5578 → 底盘 192.168.0.7:5578
 └─ usbipd                     ← 把激光雷达 USB 挂进 WSL
        │ (mirrored 网络)
[WSL2 Ubuntu 24.04 + ROS2 Jazzy]
 ├─ vehicle_bringup/bringup.launch.py   ← 一键启动全部节点
 │    ├─ chassis_node        /cmd_vel → 电机, 发布 /odom + TF(odom→base_link)
 │    ├─ ldlidar (LD19)      /scan (360° @10Hz)
 │    ├─ static TF           base_link → base_laser (z=0.18)
 │    └─ sensor_bridge_node  实验台快照 → /sensor/{temperature,humidity,noise}
 ├─ [可选] scan_repacker + slam_toolbox      (use_slam:=true, 建图)

 ├─ [可选] teleop_twist_keyboard             (use_keyboard:=true, 遥控)
 └─ lidar_avoidance / navigation(waypoint)   独立启动的功能包
```

## 2. 环境准备（每台新电脑一次性）

### 2.1 WSL2 + ROS2 Jazzy
```bash
# 安装 WSL2 Ubuntu 24.04 后:
sudo apt install ros-jazzy-desktop python3-colcon-common-extensions -y
sudo apt install ros-jazzy-slam-toolbox ros-jazzy-navigation2 \
     ros-jazzy-nav2-bringup ros-jazzy-rosbridge-server -y
echo "source /opt/ros/jazzy/setup.bash" >> ~/.bashrc
```
Windows 侧还需安装 `usbipd-win`（winget install usbipd）和 Git。

### 2.2 克隆仓库并编译
```bash
git clone git@github.com:zhuangchen557/lidar_patrol_ws.git ~/lidar_patrol_ws
cd ~/lidar_patrol_ws && colcon build
source install/setup.bash
```
> 若 `ros2 run` 找不到某个 Python 包的可执行文件，重编译该包即可（Jazzy setuptools 兼容问题已在 setup.cfg 中修复）。

### 2.3 底盘网络
Windows 有线网卡手动设为 `192.168.0.100/24`，网关留空；网线连 CAN115。
验证：`ping 192.168.0.7` 必须通。

## 3. 日常启动（每次开车三步）

**第 1 步 — 管理员 PowerShell 挂载雷达 USB**
```powershell
usbipd bind --busid <busid>     # 首次或电脑重启后; busid 用 usbipd list 查 CH340
usbipd attach --wsl Ubuntu --busid <busid>
```

**第 2 步 — 双击 `scripts/start_car.bat`**
自动完成：起 TCP 转发器 → WSL 加载串口驱动 → 编译 → 启动整车。
（也可分步手动：PowerShell 跑 `python scripts/forward_5578.py`，WSL 里 `sudo modprobe ch341 && sudo chmod 666 /dev/ttyUSB0`，然后执行第 3 步。）

**第 3 步 — 启动整车**
```bash
cd ~/lidar_patrol_ws && source install/setup.bash
ros2 launch vehicle_bringup bringup.launch.py
```
看到这三行即为成功：
```
YK_CAN SDK 已加载，已连接 CAN115 (127.0.0.1:5578)
ldlidar communication is normal / get ldlidar normal data ...
底盘节点启动完成
```

**验证清单**（新终端，记得 source）：
```bash
ros2 topic hz /scan          # ~10Hz
ros2 topic echo /odom --once # 里程计
ls /dev/ttyUSB0              # 雷达设备存在
```

## 4. 功能使用

### 4.1 键盘遥控
```bash
ros2 launch vehicle_bringup bringup.launch.py use_keyboard:=true
# 或独立运行: ros2 run teleop_twist_keyboard teleop_twist_keyboard
# i=前进 ,=后退 j=左转 l=右转 k=停  —— 注意小写、输入法切英文
```

### 4.2 SLAM 建图（生成新地图）
```bash
ros2 launch vehicle_bringup bringup.launch.py use_slam:=true
# RViz: Fixed Frame=map, Add Map(/map) + LaserScan(/scan_fixed)
# 手推车 ≤0.3m/s 绕场景一圈, 回到起点
ros2 run nav2_map_server map_saver_cli -f ~/lidar_patrol_ws/slam/maps/<名字>
```
说明：`scan_repacker` 会把 LD19 变长帧重采样为固定 360 点（解决 usbipd 抖动丢帧），SLAM 订阅 `/scan_fixed`。

### 4.3 定位与自主导航（使用已有地图）
```bash
ros2 launch vehicle_bringup bringup.launch.py use_nav2:=true
# 默认加载 slam/maps/my_map.yaml, 换地图:
ros2 launch vehicle_bringup bringup.launch.py use_nav2:=true map:=/绝对路径/map.yaml
```
操作流程：车摆到**建图时的起点附近** → RViz 点 `2D Pose Estimate` 给初始位姿 → 粒子云收敛、激光贴住地图墙线 → 点 `Nav2 Goal` 下目标点。
⚠️ 首次使用前必须完成落地标定（见 §5），否则转弯指令无效。

### 4.4 路线录制与巡检回放
```bash
# 录制(遥控走一遍, 每 0.5m/30° 存一个点):
ros2 run navigation waypoint_recorder routes/route1.json map_frame:=odom
# 回放 A — 台架直控模式(不需要地图/Nav2):
ros2 run navigation waypoint_player routes/route1.json --ros-args -p use_nav2:=false
# 回放 B — Nav2 正式模式(需 use_nav2 已启动):
ros2 run navigation waypoint_player routes/route1.json --ros-args -p use_nav2:=true -p dwell_seconds:=3.0
```
注意：参数是浮点，写 `3.0` 不能写 `3`；路线 json 按**当前目录**解析，建议 cd 到 `~/lidar_patrol_ws` 再跑。

### 4.5 激光避障测试
```bash
ros2 launch lidar_avoidance avoidance_test.launch.py
```
逻辑：前方 >1m 前进 0.2m/s；0.5~1m 减速 0.1；<0.5m 停止并向空旷侧转向。
参数在 `src/lidar_avoidance/config/avoidance.yaml` 里改，不用改代码。
⚠️ **禁止与 waypoint_player / Nav2 同时向 `/cmd_vel` 发令**，一次只能有一个控制源。

### 4.6 环境传感器与可视化平台
双击 `EnzoPatrolLab-0.2.0-windows-x64/Enzo巡迹实验台.exe`（需插入 USB 温湿度传感器，Modbus RTU 9600 8N1，自动识别 COM 口）。
数据链路：`USB传感器 → 实验台 → 网关WebSocket → sensor_bridge_node → /sensor/* 话题 → 平台显示`。
- 温湿度话题：`/sensor/temperature` `/sensor/humidity`（std_msgs/Float32）
- 验证：`ros2 topic echo /sensor/temperature`
- ⚠️ 同一串口只能被一个程序打开；实验台做识别时若长时间卡在"自动检测"，重启实验台
- Web 版开发调试：`web/robot-monitor/` 分支上 `npm install && npm run dev`

## 5. 标定工具（scripts/）

| 场景 | 命令 | 说明 |
|---|---|---|
| 悬空直线标定 | `python3 scripts/calibrate.py --lin-count` | 满速空转 5s 数圈数 |
| 悬空旋转标定 | `python3 scripts/calibrate.py --rot-only` | odom 1 圈数实际圈数 |
| **落地直线复核** | `python3 scripts/recalibrate_odom.py` | 雷达对墙测距法，车头对墙 1.5~3m |
| **落地旋转标定** | `python3 scripts/recalibrate_rot.py` | 满速原地转 4s 人工数圈 |

标定结果改 `src/vehicle_bringup/vehicle_bringup/chassis_node.py` 头部三个常量后重新编译：
```bash
colcon build --packages-select vehicle_bringup
```
**经验教训：悬空标定的参数落地后会失效（地面摩擦），换场地/换负载都应复核。**

## 7. 故障排查表（全是踩过的坑）

| 现象 | 原因 | 解决 |
|---|---|---|
| chassis 报 Connection refused | 转发器没起 | 跑 forward_5578.py |
| 连接成功但马上断/急停锁存 | **开了多个转发器进程互相踢** | 任务管理器杀光 python.exe 再起一个 |
| 雷达 /dev/ttyUSB0 不存在 | 重启后 usbipd 未挂载 | attach + modprobe ch341 + chmod 666 |
| usbipd 报 Device is not shared | bind 状态丢失 | 管理员 `usbipd bind --busid X` |
| ros2 命令找不到话题 | CLI 缓存延迟 | 加 `--no-daemon` 或等几秒重试 |
| 地面转弯不动只轻微颤 | 角速度系数悬空值过大 | 落地旋转标定，调小 MAX_ANGULAR_SPEED |
| 实验台卡"正在自动检测" | 识别流程偶发卡死 | 重启实验台（保持传感器插入）|
| set_motion 报 not connected | CAN115 只允许一个 TCP 客户端 | 不要同时跑 SDK 脚本和 chassis_node |
| Ctrl+C 退出报 context 异常 | 已修复的已知问题 | 忽略或拉最新代码 |

## 8. 安全须知

1. 任何运动测试前**先架空四轮**确认 /cmd_vel 数值正确，再落地。
2. 自主模式（Nav2 目标点 / 避障节点 / 回放）下小车**会自己动**，人员保持在急停可达范围。
3. 紧急停车：Ctrl+C 启动终端（watchdog 会自动刹车），或直接拔电机电源。
4. CAN115 与主控机之间为 TCP 明文协议，仅限实验室内网使用，勿接外网。
